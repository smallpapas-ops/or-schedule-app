員工名冊

維護員編、姓名與到職日；到職日用來依勞基法第38條試算「本服務年度」特休天數（週年制）。此清單也是匯入班表時比對每一列資料的依據。若員工中途有育嬰留職停薪、留職停薪、傷病長假等會影響特休週年計算的情況，可在「特休基準日」欄位另外填一個調整後的日期，試算會改用這個日期起算；留空則自動以到職日計算。

匯入本月排班 PDF

上傳排班表 PDF 後，系統會將每頁轉成影像，分批交給 Claude 辨識每位員工每天的班別代碼。掃描字體小、格式密，辨識結果請務必核對後再儲存——下方會顯示可直接修改的表格。

或匯入 Excel / CSV 班表

如果排班系統可以直接匯出 .xlsx / .xls / .csv，用這個方式比掃描辨識準確很多，建議優先用這個。系統會自動找出日期欄（1~天數）與員編/姓名欄，找完會先讓您確認再產生表格。

年度統計報表（全單位，仿「出缺勤暨加班補休統計報表」格式）

這張表彙整全單位當年度每個月的假別使用時數、加班（補休A／給薪B）與補休銀行結轉餘額，資料來源是各月「匯入班表」＋「調整」視窗累積的紀錄。
手術台數、業務量、開台數、編制/在職人力這幾列不是來自班表，需要另外維護，這裡先不產生；只呈現可以從班表自動算出來的假別與加班/補休部分。

班別代碼分類

設定每種代碼屬於「上班班別」「特殊假別」或「例假／排休（不列入工時也不列入假別扣抵）」。上班與假別代碼皆以 每天 = 設定時數 計算（依您先前確認，全部班別皆為 8 小時）。

雲端同步（手機／電腦共用同一份資料）

目前資料存在「這台裝置的瀏覽器」裡，換裝置不會互通。設定下面的免費 Firebase 專案後，員工名冊、班表、假別調整都會存到雲端，手機和電腦用同一個網址打開，就會看到同一份資料。
設定步驟請看對話中我給您的說明；這裡只要把 Firebase 專案的「設定物件」貼進來即可。同一組設定，每台要同步的裝置都要各貼一次（只需貼一次，之後會記住）。

第一次在「主要那台裝置」（例如平常都在用的桌機）啟用同步時，請按一次「⬆ 上傳到雲端」，把目前的員工名冊、班表都送上去；之後在其他裝置（例如手機）貼同一組設定連線後，改按「⬇ 從雲端下載」把資料抓下來。之後兩邊互相有更新，也可以照這個方向手動同步一次。

班表辨識由 Claude 讀取掃描影像產生，掃描品質、手寫或密集小字仍可能誤判，儲存前請務必核對「辨識結果」表格。特休天數試算依勞基法第38條到職日週年制；若貴單位採曆年制或另有規定，天數需另行調整。

手動調整

輸入該員工本月每天的加班時數、各假別使用時數（特休、喪假、產檢假…等，依「代碼設定」目前設定的假別列出）與補休使用時數（小時），留空視為 0。適合處理公假、喪假、生理假、婚假、事假這類容易臨時異動的班別——班表代碼還沒改過來時，先在這裡用小時數調整。這些會直接反映在上面「假別使用（天）」與「異動後時數」；其中特休(V)使用時數同時會反映在「特休總覽」的剩餘天數，補休使用時數只影響工時、不影響特休剩餘。
